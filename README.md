# Arsalan Bakhtiar Portfolio

Static portfolio site for Arsalan Bakhtiar. It uses plain HTML, CSS, and JavaScript so it can be deployed directly on GitHub Pages, Vercel, Netlify, or any static host.

## Local preview

Open `index.html` directly in a browser, or serve the repository through any local static server.

## Contact form

The contact forms create a pre-filled email to `arsalanbakhtiarab@gmail.com` using the visitor’s email application. No backend or hidden third-party service is required.

## Theme

The theme button in the header changes between the dark Ink Profile mode and a light editorial mode. The visitor’s choice is saved in local storage.
